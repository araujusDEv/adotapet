Sobre o AdotaPet

O AdotaPet foi desenvolvido por um grupo de estudantes do 3º ano do Curso Técnico em Informática da Escola Estadual Professor Antônio Dantas. O projeto começou como trabalho para a Feira de Ciências da escola e, posteriormente, passou a ser utilizado também como Trabalho de Conclusão de Curso (TCC).

Objetivo

A plataforma tem como objetivo facilitar a adoção responsável de animais, aproximando adotantes, doadores e protetores da causa animal. O foco do projeto é o município de Apodi/RN e as cidades da região.

Como funciona

Doadores e ONGs podem cadastrar animais disponíveis para adoção. Cada anúncio passa por uma etapa de análise antes de ser publicado. Quem se interessar por um animal pode enviar uma solicitação de adoção diretamente para quem cadastrou o anúncio. A plataforma também conta com uma área para divulgação de animais desaparecidos na região.

Sobre o desenvolvimento

Esta versão utiliza HTML, CSS e JavaScript no front-end e um servidor Node.js com banco de dados SQLite no back-end. Os dados são centralizados no servidor, permitindo que diferentes navegadores e dispositivos conectados ao mesmo servidor enxerguem as mesmas informações. O projeto continua sendo uma aplicação acadêmica e de demonstração, não um serviço público de produção.
